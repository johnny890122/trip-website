## 3. 路線（單向）與步行
後街吊腳樓廣場 → （沿鳳凰溪步道、過金碧橋）→ 寶輪寺 → 橫街 → 正街北端（江邊）→ 沿正街往西南 → 千年古鎮鷄雜。
`node scripts/build-spots.js --trip 2026-12`（OSRM foot，分鐘＝距離 ÷ 80，2026-11-20）：

| 段 | 公尺 | 分 |
|---|---|---|
| 後街吊腳樓廣場 → 寶輪寺 | 849 | 11 |
| 寶輪寺 → 磁器口橫街 | 30 | 0 |
| 橫街 → 正街北端（江邊） | 212 | 3 |
| 正街北端 → 正街（往回走的點） | 186 | 2 |
| 正街 → 千年古鎮鷄雜 | 103 | 1 |
| 合計 | 約 1.4 km（腳本輸出） | 約 17 |

沒有一段畫成直線。

- **停留時間是估算**：後街 14:20～14:44（含走過去）、寶輪寺 14:55～15:40、橫街喝茶 15:40～16:17、江邊 16:20～16:53、正街 16:55～17:28、17:30 到店。
- **拿掉的點與原因**：
  - 重慶1949大劇院：第一版放在後街之後，OSRM 路線要先往西繞到大馬路再回來（578 m，直線約 265 m），而且它不是必看點 → 拿掉。路線本來就沿鳳凰溪步道經過它北側附近（研判，看 OSRM 幾何）。
  - 黃桷坪牌坊、正街南段、金蓉門：在晚餐店的西南邊，下午去就要走回頭路。**飯後 18:45 走回磁器口站時會經過正街南段**（店 → 站 OSRM 965 m，`1209_重慶動線`），所以不排進下午。黃桷坪牌坊在正街東南的支路，飯後要不要繞未算。
- **唯一的回頭路**：橫街接正街的路口（正街第 28 節點）→ 江邊端約 95 m（研判，看座標），再走回來。江邊是死巷，必看點在那裡，所以保留。
- 行程卡原寫「磁器口站 → 古鎮步行約 13 分（OSRM 1071 m），約 14:20 才到古鎮」：那是到 Nominatim 古鎮中心點的距離。從站走到後街吊腳樓廣場的距離**本次沒算**（兩點直線研判約 260 m）。14:20 不改，到早了就在後街多逛。
